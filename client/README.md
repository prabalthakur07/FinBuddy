# FinBuddy 💰

FinBuddy is a personal finance management web application designed to help users track their income and expenses, monitor their financial activity, and explore useful financial schemes.

## ✨ Features

- 📊 Financial dashboard with charts and statistics
- 💰 Track income and expenses
- 🏦 Manage bank account information
- 📋 View financial/government schemes
- 🔐 User registration and login
- 📈 Monitor savings and spending
- 📱 Responsive user interface

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- MongoDB Atlas
